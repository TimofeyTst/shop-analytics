## Вариант
Вариант 9. Интернет-магазин

Elasticsearch.
1. Типы документов (json):
Покупка:
{index, doc_type, id, body: {id_покупателя, персональные_данные_покупателя*, дата_покупки, id_товара, наименование, количество_единиц, стоимость}}
Товар:
{index, doc_type, id, body: {наименование, дата_поступления_партии, количество_на_складе, количество_проданных, стоимость_единицы_товара, описание*, ссылка_на_избражение}}
2. Требование к анализатору:
поля, отмеченные *, разделить на слова, убрать пунктуацию с помощью токенизатора standart (русский), перевести все токены в нижний регистр, убрать токены, находящиеся в списке стоп-слов.
3. Запросы с вложенной агрегацией:
- разбить товары по дате поступления партии с периодом 1 месяц, для каждой группы определить число проданных товаров по каждому наименованию,
- определить общую стоимость проданных товаров за последние 2 месяца.

Neo4j.
1. По данным из Elasticsearch заполнить графовую базу данных Покупка(id_покупки, дата_покупки, персональные_данные_покупателя) – Включает(количество_единиц, стоимость) – Товар(id_товара, наименование).
Примечание.  В скобках приведены свойства узлов и отношения (связи), глагол – это отношение.
2. Разработать и реализовать запрос: какой покупатель заплатил бо’льшую стоимость за все купленные им товары. 

Spark
1. По данным из Elasticsearch сформировать csv-файлы (с внутренней схемой) таблиц «Покупатель», «Покупки», «Товары» и сохранить их в файловой системе HDFS. 
2. Написать запрос select:  найти покупателя и товар с максимальной стоимостью покупки.
3. Реализовать этот запрос в Spark. Построить временную диаграмму его выполнения по результатам работы монитора.

Pgvector
1. Преобразовать документы 1-го типа в векторы.
2. Сохранить векторы в векторной БД.
3. Найти 3 самых близких документа для какого-либо одного документа.
